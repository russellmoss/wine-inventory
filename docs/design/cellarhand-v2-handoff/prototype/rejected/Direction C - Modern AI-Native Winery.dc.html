AI is infrastructure, not a panel: it ranks the queue, explains what's abnormal, and drafts writes that only a human commits.

One field, three intents — Do, Go to, Ask — always in that order, so the deterministic results are always above the generated one. "All of Cellarhand" in the header is the full, boring, complete directory for anyone who'd rather browse.

Now is not a dashboard: no aggregate metrics, no charts, no "total wine on hand". Every item is a thing that needs a decision, ranked by consequence, each with the records the ranking came from and one primary verb. Rank order is labelled as Cellarhand's opinion with the plain queue one click away — the adaptive layer never becomes the only way to see the truth.

Four states, never blurred: a recommendation is text; a draft is an unapplied change with a diff; a confirmed action is a scheduled write with your name on it; a completed action is a ledger line. Only the third and fourth exist on the server.

The brief is an act list, not a task list: each row is a physical thing done to wine, with its ledger consequence attached. Production context lives at the top as a six-stage bar where solid means recorded and hollow means planned — the compact form of the full lineage view, and the same component reused on lots and vessels.
